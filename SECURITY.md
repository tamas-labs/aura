# Security Policy

## Supported versions

Aura is currently pre-1.0 (`0.x`). Only the latest version published on npm receives security
fixes.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, report privately via one of:

- [GitHub Security Advisories](https://github.com/tamas-labs/aura/security/advisories/new)
  (preferred)
- Email: tbalint78@gmail.com

Please include:

- A description of the vulnerability and its potential impact
- Steps to reproduce (proof-of-concept code, if possible)
- The affected version(s)

You should receive a response within a few days. Confirmed vulnerabilities will be patched and
disclosed via a GitHub Security Advisory, with a corresponding `CHANGELOG.md` entry once a fix is
released.
